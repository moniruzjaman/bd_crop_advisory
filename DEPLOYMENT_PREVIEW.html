🏗️ System Architecture

Farmer (Mobile/WhatsApp) ↓ NGINX (SSL/Reverse Proxy) ↓ FastAPI Backend (Port 8000) ↓├→ CNN Symptom Classifier ↓├→ Plantwise Rule Engine ↓├→ BRRI/BARI Advisory KB ↓└→ Bangla Explainer ↓ PostgreSQL + Redis

✨ Key Features

  • AI Symptom Classification (11 categories)
  • Plantwise Elimination Rule Engine
  • Bangladesh-Authoritative Advisory
  • Bangla Language Support
  • WhatsApp Button Messages
  • MIS Dashboard & Early Warning
⚠️ AI Governance:
• No final disease confirmation
• No pesticide dosage (ETL only)
• Always include disclaimer
