🇧🇩 National AI-Enabled Crop Health Advisory System

Ministry of Agriculture | Government of Bangladesh | Plantwise Protocol

Government Grade

🎯 System Objective

Build a national-scale AI-assisted crop diagnosis and advisory platform that accepts crop images via mobile/WhatsApp, performs symptom-first classification using Plantwise protocol, and generates Bangladesh-authoritative advisory compliant with DAE, BRRI, BARI, SRDI, and BARC guidelines.

⚙️ Rule Engine

JSON-based elimination logic mapping symptoms + observations to probable cause groups.

# Example Rule for Leaf Spot { "leaf_spot": { "observation_rules": { "concentric_rings": { "cause": "Fungal", "confidence": 0.8 }, "water_soaked": { "cause": "Bacterial", "confidence": 0.75 } }, "default": { "cause": "Fungal", "confidence": 0.6 } } }
Allowed Causes: Fungal Bacterial Viral Insect Nematode
