🚀 DEPLOYMENT METHODS:

1. UNIVERSAL SETUP (Recommended)
   ┌─────────────────────────────────────┐
   │ chmod +x setup.sh                   │
   │ ./setup.sh deploy                   │
   └─────────────────────────────────────┘
   ✓ Auto-installs Docker if missing
   ✓ Generates SSL certificates
   ✓ Sets up environment
   ✓ Builds and deploys all services
   ✓ Performs health checks

2. WINDOWS
   ┌─────────────────────────────────────┐
   │ setup.bat                           │
   └─────────────────────────────────────┘
   ✓ One-click Windows deployment

3. PYTHON MANAGER
   ┌─────────────────────────────────────┐
   │ python auto_deploy.py deploy        │
   │ python auto_deploy.py status        │
   │ python auto_deploy.py logs          │
   │ python auto_deploy.py backup        │
   └─────────────────────────────────────┘
   ✓ Cross-platform advanced control

4. INTERACTIVE WIZARD
   ┌─────────────────────────────────────┐
   │ python install_wizard.py              │
   └─────────────────────────────────────┘
   ✓ Guided configuration
   ✓ Custom settings

5. MANUAL DOCKER
   ┌─────────────────────────────────────┐
   │ cd backend                            │
   │ docker-compose up -d                  │
   └─────────────────────────────────────┘
   ✓ For developers
